The Complete Picture — 50 Samples, Honest Finding

Across all 50 validation samples: zero strict-correct semantic groundings found. Every condition variable is a generic abstract name. CFFT improved solver feasibility (91.2%→94.0%) by fixing syntactic errors OR-Tools can detect. But semantic naming — the difference between exception_contract_XXXX and health_safety_claim_filed — requires supervision beyond binary feasibility. This is the paper's deepest finding and clearest future direction: richer training signals such as semantic similarity between condition variables and exception trigger text, or human-in-the-loop correction of condition semantics.
