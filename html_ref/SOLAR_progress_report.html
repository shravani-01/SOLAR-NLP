Key Finding
Exception Extraction vs. Grounding

The Extraction-Grounding Gap

General-purpose LLMs achieve up to 95.3% exception extraction by identifying surface-level spans — but they cannot translate these spans into executable solver constraints. SOLAR achieves 94.8% conditional realization, but manual evaluation reveals only ~20% strict semantic grounding. Models learn when to use conditional constraints but struggle with what condition to apply. This gap is the core motivation for CFFT.

Literature
Related Work — Two Communities
Part 1 · Regulatory NLP (F1 metric)
ObliQA (2024)
arxiv:2409.05677 · RegNLP

27,869 QA pairs from Abu Dhabi Global Markets financial regulations. Automated question-passage generation from real regulatory documents. Evaluated with F1.

SOLAR: same domain (real documents) but extracts structured constraints and grounds them in solver code — ObliQA only answers questions.
Zhang & El-Gohary (2015)
J. Computing in Civil Engineering

Rule-based NLP for construction regulatory documents. Deontic patterns (shall, must, may). Extracts subject, attribute, operator, restriction tuples. F1 = 0.82.

SOLAR: same task (deontic extraction from real docs), same metric (F1), but LLM-based (0.858 vs 0.82) + adds solver verification they never had.
RegNLP Workshop (COLING 2025)
COLING 2025

First dedicated workshop on Regulatory NLP. Covers obligation extraction, compliance checking, regulatory document parsing. F1 is standard metric.

SOLAR's first half belongs to this community. No RegNLP paper adds formal solver verification.
CUAD (2021)
NeurIPS 2021

Contract Understanding Atticus Dataset. 510 legal contracts with 13,000+ expert annotations across 41 clause types. Legal contract clause identification.

SOLAR: extends legal NLP to operational constraints with formal solver grounding — CUAD stops at clause identification.
Part 2 · Neuro-symbolic CP (SA% / feasibility metric)
ConstraintLLM (EMNLP 2025)
EMNLP 2025 · Related Work

Fine-tunes Qwen2.5-Coder-32B on IndusCP (140 clean problems). CARM retrieval + Tree-of-Thoughts + inference-time self-correction. SA% = 51.3% on IndusCP.

Key difference: ConstraintLLM uses clean purpose-written inputs, never updates weights from solver. SOLAR reads real documents + CFFT updates weights. Different solver (PyCSP3/Choco vs OR-Tools).
SIRL (NeurIPS 2025)
NeurIPS 2025 · Related Work

Solver-Informed Reinforcement Learning. Uses RL with Verifiable Reward — solver provides feasibility + solution quality as reward signal. Gurobi/COPT solvers.

CFFT vs SIRL: CFFT is targeted SFT (not RL). Simpler, more stable, works on 187 pairs. SIRL needs thousands of rollouts and careful KL tuning.
NL4OPT (NeurIPS 2022)
NeurIPS 2022 Competition

271 linear optimization problems from word descriptions. Clean structured inputs. LP formulations only. SA% metric.

Plan to retrain SOLAR on NL4OPT training data and report SA% for fair comparison in Part 2 table.
IndusCP / LGPs
ConstraintLLM paper benchmarks

IndusCP: 140 industrial CP problems (scheduling, packing, routing). LGPs: 100 logic grid puzzles. Both use clean purpose-written descriptions.

Plan to evaluate SOLAR on these after retraining for fair SA% comparison. Domain gap expected without retraining.
